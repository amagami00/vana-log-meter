# vana-log-meter

FFXI クライアントのチャットログ（`FINAL FANTASY XI/TEMP/{1,2}_{0..19}.log`）を読み、戦闘を集計するツール。
Windows と Mac を対象にする。

## 読み取る範囲

- **ログファイルを読むだけ**。ゲームのメモリやパケットには触れない。ゲームへの書き込みもしない。
- ログに出ない値（時刻・命中判定の内訳など）は取得できない。

## 構成

| ディレクトリ | 内容 |
|---|---|
| `packages/vana_log_core` | ログの解析・集計・CSV/JSON 出力（Dart。UI を持たない） |
| `app` | 監視・集計・書き出しの画面（Flutter。Windows / macOS） |
| `filters` | フィルタセットのサンプル（ソーティのボス） |

## フィルタセット

敵の絞り込みを名前のまとまりで ON/OFF する。

1. 任意のフォルダに `*.json` を置く（UTF-8。BOM 付きも読む）。
2. 「フィルタ」タブでそのフォルダを選ぶ。ファイルを足したら「読み直す」を押す。
3. セットを ON にすると、その敵を「集計」タブの絞り込みに加える。OFF で外す。

```json
{"name": "ソーティ ボス", "enemies": ["Ghatjot", "Leshonn", "Aminon"]}
```

- `enemies` はログの表記と完全に一致する名前だけを選ぶ。
- 1 ファイルに複数のセットを書くときは配列にする。
- まだログに出ていない敵は、出た時点で絞り込みに入る。セットの敵が 1 体も出ていない間は、すべての敵を集計する。
